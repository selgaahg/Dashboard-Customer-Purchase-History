# Dashboard-Customer-Purchase-History
This project is an interactive Excel dashboard built to analyze customer purchase history and sales performance. The dashboard provides insights into customer transactions, revenue trends, product categories, payment methods, and customer ratings using Pivot Tables and data visualization features in Microsoft Excel.

Features: Sales and revenue analysis, customer purchase tracking, product category performance, payment method distribution, customer review rating analysis, interactive dashboard with Pivot Tables and charts

Tools Used: Microsoft Excel, Pivot Tables, Charts & Data Visualization, Data Cleaning and Processing, and Dataset Information

The dataset contains: Customer ID and Name, Product and Product Category, Purchase Date, Quantity and Unit Price, Payment Method, Review Rating, Total Purchase Price

The purpose of this project is to transform raw customer transaction data into meaningful business insights that can support decision-making and improve understanding of customer purchasing behavior.
